# Per-spec SRSP overrides for this API endpoint.

- `test-command`: command to run in `/srsp-verify` and `/srsp-apply`.
- `commit-prefix`: prefix for generated commit messages.
- `branch-prefix`: prefix for feature branch suggestions.
- `pr-target`: overrides the default PR target branch.
- `coverage-command`: command used by `/srsp-coverage`.
- `ticket-base-url`: optional tracker base URL for `/srsp-link`.
